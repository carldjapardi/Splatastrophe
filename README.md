# Splatastrophe

An interactive playground for reconstructing buildings with Gaussian splatting and exploring how they bend, sway, and respond to forces.

## Project planning

Read the [implementation plan](docs/IMPLEMENTATION_PLAN.md) for the proposed architecture, staged experiments, multi-building playground requirements, schedule, and evaluation criteria.

The project is currently in the planning stage. One building is the first technical milestone; the intended product supports a reusable library of buildings and user-triggered actions.
